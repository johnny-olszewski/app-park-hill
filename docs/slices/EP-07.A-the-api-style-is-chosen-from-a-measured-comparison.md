# EP-07.A: The API style is chosen from a measured comparison

A spike slice (guide 7.1 rule 13): `community.group` is rebuilt on iOS over GraphQL on an unmerged `spike/` branch, and the findings report that compares it with the current style merges to `main`.

| # | Behavior acceptance criterion |
|---|---|
| B1 | On the spike branch, in Local, a member opens a group in Community, sees its detail from GraphQL, taps Leave, confirms and lands on an updated Community tab |
| B2 | On the spike branch, in Local, a leader swipes a member's row, confirms and the member is gone; another leader's row has no swipe action, because the backend's capability field says so |
| B3 | On the spike branch, a person who can see no group gets no group rows from GraphQL, shown by a pgTAP test querying as that person |
| B4 | `docs/spikes/EP-07.A-graphql.md` on `main` compares both styles for `community.group` with the measurements SUP-026 and IOS-028 list, and ends in a recommendation |
